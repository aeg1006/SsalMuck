# ssalmuck beta 1.5.0

## 변경사항
- 메인 홍보 문구 제거
- 밥점수를 일반 별점으로 변경
- 별점 평균과 참여 인원만 간결하게 표시
- 주황색 중심의 강조색과 직관적 이모지 복원
- 공식 페이지 URL을 실제 주소 형태의 hyperlink로 표시
- 태그를 카드와 상세 화면에 표시
- 쌀먹 예정/완료 선택 상태를 강한 색상으로 표시
- 관리자 공통 태그 추가·수정·비활성화·삭제 기능 추가

## 업데이트
1. Supabase SQL Editor에서 `supabase-migration-beta-1.5.0.sql` 실행
2. 폴더 안의 웹 파일을 GitHub 저장소 최상위에 업로드
3. GitHub Pages 배포 완료 후 새로고침
