# ssalmuck beta 2.0.0

광고 없이 돈 되는 이벤트를 빠르게 비교하고 참여할 수 있는 이벤트 플랫폼입니다.

## beta 2.0.0

- 기본 화면을 모바일 이벤트 앱처럼 간결한 텍스트 목록형 UI로 변경
- `간단히 보기`와 `상세 보기` 전환 기능 추가
- 간단히 보기에서 참여 방법, 보상, 제목, D-day를 빠르게 확인
- 상세 화면에서 참여 방법, 경품 정보, 마감일을 우선 표시
- 참여 링크를 큰 `이벤트 참여하기` 버튼으로 변경
- 기존 상세 카드 UI와 Supabase 데이터는 그대로 유지
- 별도 DB migration 불필요

## 배포

폴더 안 파일 전체를 GitHub 저장소 최상위에 업로드하면 됩니다. `README.md`도 함께 덮어써야 GitHub 첫 화면의 버전 설명이 갱신됩니다.
