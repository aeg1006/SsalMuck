# ssalmuck beta 1.7.0

## 변경사항
- 이벤트 등록 폼 정리: DB에서 실제로 필수인 항목(제목, 카테고리, 보상 썸네일 표시, 마감일, 상세설명)에만 빨간 * 표시를 붙이고 `required`를 적용. 나머지(보상 종류, 지급 방식, 상세내역, 자격요건, 참여 링크 등)는 비워둘 수 있도록 `required`를 제거.
- 보상 입력에서 "금액·가치" 숫자 입력칸을 제거. 보상 금액/가치는 "썸네일 표시"와 "상세내역"에 직접 입력하는 방식으로 통일. "종류" 드롭다운은 필터링용으로 유지.
  - 이에 따라 메인 페이지 정렬 옵션에서 더 이상 의미가 없어진 "보상 높은 순"을 제거함(reward_amount 값이 더 이상 입력되지 않기 때문). 필요하면 알려주세요, 다시 살릴 수 있어요.
- "소요시간·귀찮음" 섹션 이름을 "참여 방법"으로 변경 (글쓰기 폼, 태그 라벨, 관리자 공통 태그 관리 화면 모두 반영). 다른 후보: "참여 절차", "참여 난이도" — 마음에 드는 쪽으로 쉽게 바꿀 수 있습니다.
- 이벤트 등록/상세 화면에서 "당첨자 수" 입력·표시를 제거 (당첨 발표일은 유지).
- 헤더 네비게이션에 "소개" 탭 추가, `about.html` 신설. 쌀먹 이벤트를 찾는 사람들을 위한 사이트라는 소개와 피드백 이메일 안내 포함.
  - **주의**: `about.html`의 피드백 이메일은 `feedback@ssalmuck.com` 임시값입니다. 실제 이메일 주소로 꼭 교체해주세요.

## 업데이트
1. Supabase SQL Editor에서 `supabase-migration-beta-1.6.0.sql`을 실행합니다. (reward_amount, winner_count 컬럼을 삭제하는 마이그레이션이라 기존 값이 지워집니다. 데이터를 남겨두고 싶다면 실행하지 않아도 웹 화면은 정상 동작합니다.)
2. 폴더 안의 웹 파일 전체를 기존 배포 위치(Netlify 또는 GitHub Pages)에 업로드합니다.
3. `about.html`의 피드백 이메일 주소를 실제 주소로 수정한 뒤 배포하세요.
