# ssalmuck — beta 1.9.0

돈이 되는 이벤트를 한곳에 모아 보고, 보상·참여 방법·소요시간을 빠르게 비교할 수 있는 서비스입니다.

## 현재 기능

- Supabase 기반 회원가입·로그인
- 사용자 이벤트 등록·수정
- 보상 / 참여 방법 / 예상 소요시간 중심의 카드
- 댓글과 별점
- 쌀먹 예정 / 쌀먹 완료 저장
- 인기 쌀먹 집계
- 마이페이지와 선택형 사용자 정보
- 관리자 공지·게시글·태그 관리
- 대표 이미지 업로드

## beta 1.9.0 변경사항

- GitHub 첫 화면의 README를 현재 버전으로 갱신
- 별점 선택 시 선택한 점수까지 별이 모두 채워지도록 수정
- 글쓰기 입력란을 제목, 보상, 참여 방법, 예상 소요시간, 상세 내역, 마감일, 참여 링크, 대표 이미지로 간소화
- 마감일을 선택 입력으로 변경
- 이벤트 상세 상단에 참여 링크를 강조 표시
- 마이페이지 탭 표시 오류 수정: `나의 정보`는 탭을 눌렀을 때만 표시
- asset cache version을 1.9.0으로 변경

## 업데이트

1. Supabase SQL Editor에서 `supabase-migration-beta-1.9.0.sql` 실행
2. 이 폴더 안의 파일을 GitHub 저장소 최상위에 업로드
3. `Commit changes` 후 GitHub Pages 배포 완료 확인
4. 필요하면 `Ctrl + F5`로 강력 새로고침

기존 이벤트·회원·댓글·별점 데이터는 삭제하지 않습니다.
