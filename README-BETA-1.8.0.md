# ssalmuck beta 1.8.0

## 주요 변경
- 필수 표시 별표를 항목명 바로 옆에 배치하고 안내 문구 추가
- 마이페이지를 `활동`과 `나의 정보` 탭으로 분리
- 선택 정보에 지역, 나이, 직업, 성별 추가
- 이벤트 지역 전용 입력란과 카테고리 입력란 제거
- 지역·직업·성별·연령 추천을 자격요건 태그로 통합
- 메인 카테고리 필터를 태그 필터로 교체
- 썸네일 핵심 정보를 `보상 / 참여방법 / 소요시간`으로 변경

## 업데이트 순서
1. Supabase SQL Editor에서 `supabase-migration-beta-1.8.0.sql` 실행
2. 이 폴더 안의 사이트 파일 전체를 GitHub 저장소 최상위에 업로드
3. GitHub Pages 배포 후 새로고침

기존 데이터는 삭제되지 않습니다.
