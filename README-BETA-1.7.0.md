# ssalmuck beta 1.7.0

## 주요 변경
- 카테고리, 보상 종류, 지급 방식의 직접 입력 제거 및 `기타` 통합
- 소개 페이지 문구와 문의 이메일 수정
- 평균 별점을 별 개수와 반쪽 별 형태로 표시
- 마이페이지 선택 지역 설정 추가
- 이벤트 지역 자격요건 추가
- 로그인 사용자의 지역과 일치하는 이벤트를 `📍 맞춤 추천`으로 우선 표시

## 업데이트
1. Supabase SQL Editor에서 `supabase-migration-beta-1.7.0.sql` 실행
2. 이 폴더의 웹 파일을 GitHub 저장소 최상위에 업로드
3. GitHub Pages 배포 완료 후 강력 새로고침

지역 정보는 선택이며, 입력하지 않아도 서비스 이용에 제한이 없습니다.
