# ssalmuck beta 1.4.0

## 변경사항
- 전체 문구와 UI를 더 간결하게 정리
- 필터 정렬과 폭 개선
- `따끈한 밥/취사중/완료`를 `인기 쌀먹/쌀먹 예정/쌀먹 완료`로 변경
- 카테고리 직접 입력은 `직접 입력` 선택 시에만 노출
- 보상·귀찮음·자격요건 태그 시스템 추가
- 썸네일은 보상과 소요시간만 강조
- 상세 화면을 보상/소요시간/자격요건/추가 안내 순으로 재구성
- 밥점수는 1~5 정수 단위로 단순화

## 업데이트
1. Supabase SQL Editor에서 `supabase-migration-beta-1.4.0.sql` 실행
2. 이 폴더의 파일들을 GitHub 저장소 최상위에 업로드
3. Commit 후 GitHub Pages 배포 완료 확인
