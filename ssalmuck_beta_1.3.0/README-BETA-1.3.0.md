# ssalmuck beta 1.3.0

## 새 기능
- 이벤트별 `취사중` / `쌀먹완료` 상태 저장
- 공개 취사중·완료 인원 카운터
- 참여가 많은 이벤트를 보여주는 `🔥 따끈한 밥` 코너
- 마이페이지의 `쌀먹할 예정` 및 `내가 쌀먹한 이벤트` 목록
- 추첨 이벤트용 당첨자 발표일·당첨자 수 입력

## 업데이트 순서
1. Supabase SQL Editor에서 `supabase-migration-beta-1.3.0.sql` 전체를 실행합니다.
2. 성공 메시지를 확인합니다. 기존 이벤트 데이터는 삭제되지 않습니다.
3. `ssalmuck_beta_1.3.0` 폴더를 기존 Netlify 프로젝트 Deploys 화면에 업로드합니다.

## 인기 산정
현재 `따끈한 밥` 점수는 `취사중 1점 + 쌀먹완료 2점`으로 계산하며 상위 4개를 보여줍니다.
